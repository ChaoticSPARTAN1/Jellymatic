# Media

Trailers, short clips and pictures for Jellymatic.

| Folder | What is in it |
|---|---|
| `jellymatic/` | Jellymatic trailer (1080x1080 and 1920x1080), four short clips (start-up menu, Jellyfin, Chromatic Manager, Remote Pilot), teaser pictures |
| `howto/` | How to stream Jellyfin over Wi-Fi from a Chromatic to an Analogue Pocket with a link cable (42 s, both sizes), and a picture. See [Pocket link](../docs/Pocket-link.md) |

All videos are MP4 (H.264, 30 fps, AAC sound). The PocketFin trailer and clips are in the
[PocketFin](https://github.com/ChaoticSPARTAN1/PocketFin/tree/main/media) repository.
