# Remote Pilot wiki

Remote Pilot lets you see and control a **ModRetro Chromatic** from your PC's web browser, over USB
or your home Wi-Fi. It is a testing tool for people and AI assistants.

## The short version

1. [Install](Install.md): run `Setup-RemotePilot.ps1`, then `Start-RemotePilot.cmd`.
2. Open <http://127.0.0.1:38764/> and pick **ModRetro Chromatic**.
3. Try a **Simulated** connection first. For a real console, follow
   [Pairing with a Chromatic](Pairing-with-a-Chromatic.md).
