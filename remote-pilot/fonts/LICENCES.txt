Fonts used by Remote Pilot's Chromatic preset (presets/chromatic/theme.css), served locally by
receiver.py at /fonts/<file> and loaded with @font-face. No CDN is used.

- heading-PressStart2P-Regular.ttf: Press Start 2P by CodeMan38. SIL Open Font License 1.1,
  licence text in OFL-PressStart2P.txt.
- body-Silkscreen-Regular.ttf: Silkscreen by The Silkscreen Project Authors. SIL Open Font
  License 1.1, licence text in OFL-Silkscreen.txt.

Both files are unmodified copies of the ones in the Chromatic Manager project
(Jellymatic's scripts/chromatic_gui_fonts/; see README.txt here for their
origin); only the file names carry the heading-/body- prefixes. Same SHA-256 as those copies,
checked 2026-11-08:

  heading-PressStart2P-Regular.ttf  034c77f1f05ec89421e4a63f0e3a4ca1ecf852cc6d2bf611f126f275728e017d
